## 🎓 Дипломный проект

### 📋 [SecureVote](https://secvote.web.app) — платформа анонимного голосования
Веб-сервис для проведения анонимных опросов с защитой на уровне Firestore Security Rules и хешированием UID через Web Crypto API (SHA-256).
- **Frontend:** Vanilla JS, адаптивный интерфейс
- **Backend:** Firebase (Auth, Firestore, Hosting)
- **Особенности:** анонимизация пользователей, защита от XSS, безопасные HTTP-заголовки
